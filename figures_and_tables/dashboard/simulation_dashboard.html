How these numbers are defined
  • One row of the table, and one comparison box, is a simulation = one simulation category (A–N) inside one parameter arm.
  • Every fastEnloc number comes from the same reduction the report PDFs use (enloc_best_rows): one best row per GWAS trait per replicate — NA-correct first, then correct, then highest RCP — pooled over the arm's replicates.
  • True positive: the eQTL and GWAS trait ids match and RCP > cutoff. False positive: they do not match and RCP > cutoff. Underpowered colocalization: RCP ≤ cutoff. Underpowered fine-mapping: the trait has no fastEnloc signal at all.
  • TPR / FPR are both out of all GWAS traits in the panel — the denominator the report tables use, so TPR is colocalization power and FPR is not 1 − precision.
  • FDR = FP / (TP + FP): of the loci actually called at this cutoff, the share whose eQTL partner is the wrong one. It is 1 − precision, so it is the y-axis of the precision–recall curve read upside down, and it is the one row here whose denominator is not all GWAS traits. Undefined (shown as –) when nothing is called.
  • Because the reduction keeps one call per GWAS trait and prefers a correct pairing over a higher-RCP wrong one, a locus that colocalizes correctly is never also counted as a false positive — so FDR here is a lower bound on the rate of spurious above-cutoff pairings.
  • Significant loci are those whose causal variant clears χ² = 29.72 (p < 5×10⁻⁸) in expectation in a GWAS of the selected size — deterministic in the simulated β and MAF, no sampling. This is the expected-power definition the report PDFs use, not the observed lead-SNP p-value of the simulated study.
  • The sig. loci rows (and the left table's sig. loci switch) apply that restriction to the whole tally: a true positive counts only if its GWAS trait is significant, a false positive likewise, and the TPR/FPR denominator becomes the number of significant loci rather than all GWAS traits. FDR, being out of the calls made, is affected only through which calls survive the restriction.
  • Under power-weighted causal sampling there is no frequency floor on the causal pool, so the causative cutoff is reported as the sampling scheme; the arm's causal_min_maf token only gates flanking GTEx-only loci.
  • Whiskers on the MAF-by-selection-coefficient plot reach the furthest variant within 1.5 IQR of the hinge; individual outliers are counted in the tooltip rather than drawn.
